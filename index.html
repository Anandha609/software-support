Software Support Knowledge Base

This internal knowledge base contains troubleshooting guidance for common software issues reported by employees across Windows 11, macOS, Microsoft 365, Adobe Creative Suite, SAP, internal business applications, Chrome, and Microsoft Edge.

Microsoft 365 Activation Issues

If Microsoft 365 shows an activation error after a password reset, sign out of all Office applications, restart the device, and sign in again using your corporate account.

Verify that the device has internet access and that the system time is synchronized. Activation failures may occur when the device clock is incorrect by more than a few minutes.

If the error persists, open an elevated Command Prompt and run the Office licensing repair utility, then restart the computer and test activation again.

Adobe Creative Suite Crashes

Clear the Adobe cache and install the latest patches from Creative Cloud. Ensure that GPU acceleration is enabled only if the graphics driver is up to date.

If Photoshop or Illustrator closes unexpectedly, reset application preferences while launching the application and test with a new user profile.

Chrome and Edge Freezing

Disable recently installed extensions and test in an InPrivate or Incognito window. Clear browser cache, cookies, and site data if the issue occurs only on specific websites.

Hardware acceleration can also cause freezing on some devices. Disable it from browser settings and restart the browser.

Windows 11 Update Failures

Run the Windows Update Troubleshooter and ensure that the Windows Update service, Background Intelligent Transfer Service, and Cryptographic Services are running.

Corrupted update components can be repaired by resetting the SoftwareDistribution and Catroot2 folders and then checking for updates again.

Internal Tool Installation Problems

Confirm that the installer version matches the operating system architecture. Temporarily disable third-party antivirus software if the installer is blocked.

Capture the exact error message, installation log location, and the time the failure occurred.

SAP Launch Issues

Verify VPN connectivity, clear SAP GUI cache, and confirm that the correct environment is selected. Re-import the SAP connection entries if they are missing.

Driver Compatibility

Check Device Manager for warning icons. Install the driver version approved by the IT team rather than the latest vendor driver when compatibility issues are reported.

Software Licensing

Record the license type, expiration date, and activation method. Subscription licenses should be validated against the assigned corporate account.

Diagnostic Information to Collect

  • Exact error message
  • When the issue started
  • Recent changes made
  • Operating system version
  • Application version
  • Whether the issue affects other users

General Troubleshooting Notes

Restarting the affected application should always be attempted before advanced troubleshooting. Collect screenshots whenever possible to help correlate the issue with known incidents.

Ensure that pending operating system updates are installed and that the device has sufficient free disk space for application updates and temporary files.

For browser-related issues, test with a different user profile to determine whether the problem is caused by corrupted profile data.

Network interruptions may cause activation failures, download failures, and incomplete updates. Verify connectivity to corporate services and external vendor endpoints.

If the issue requires administrative privileges, document the steps already performed and escalate to the Level 2 support team with the collected diagnostics.
