Software Support Knowledge Base

This internal knowledge base contains troubleshooting guidance for common software issues reported by employees across Windows 11, Microsoft 365, Adobe Creative Suite, Chrome, and internal business applications.

Microsoft 365 Activation Issues

If Microsoft 365 shows an activation error after a password reset, sign out of all Office applications, restart the device, and sign in again using your corporate account.

Verify that the device has internet access and that the system time is synchronized.

Adobe Creative Suite Crashes

Clear the Adobe cache and install the latest patches from Creative Cloud.

Chrome and Edge Freezing

Disable recently installed extensions and test in an Incognito or InPrivate window.

Windows 11 Update Failures

Run the Windows Update Troubleshooter and ensure that the Windows Update service is running correctly.

Internal Tool Installation Problems

Confirm that the installer version matches the operating system architecture.

Diagnostic Information to Collect

  • Exact error message
  • When the issue started
  • Recent changes made
  • Operating system version
  • Application version
